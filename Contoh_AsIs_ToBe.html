Contoh As-Is → Analisis → To-Be

Kasus latihan: proses internal toko setelah pesanan diterima. Kedua diagram sengaja hanya merinci satu peserta, Pool Toko. Kasir dan Gudang adalah Lane dalam Pool yang sama; seluruh panah urutan adalah Sequence Flow. Interaksi Bank/Pelanggan perlu Pool tersendiri dan Message Flow jika dirinci.

1. As-Is: pencatatan ganda

Kasir menerima data pesanan, mencatatnya pada buku, lalu mengetik ulang ke rekap. Gudang menyiapkan paket. Data pesanan berasal dari formulir yang sudah diterima; model berakhir ketika paket siap diambil.

2. Analisis dan gap

Masalah As-IsAnalisisPerubahan To-BeKontrol yang dipertahankan
Menyalin informasi yang sudah tersediaNVA: over-processing; konfirmasi narasumber dan ukur waktu salinSatu entri melalui aplikasi POS; data digunakan bersamaValidasi isian dan pencatatan audit
Status pembayaran diperiksa manualBVA: kontrol pembayaran diperlukanService Task memeriksa status melalui APIOtorisasi, verifikasi hasil, dan penanganan gagal

3. To-Be: data bersama dan keputusan jelas

Kasir memasukkan pesanan pada POS (User Task). Sistem memanggil API status pembayaran (Service Task). XOR memisahkan hasil: valid menuju Gudang; tidak valid menuju pemberitahuan penolakan. Penyedia API tidak dirinci pada diagram internal ini.

Lane menjelaskan tanggung jawab; hak akses, TLS, dan pengamanan data harus diterapkan pada aplikasi. Ketika API gagal atau timeout, prosedur fallback harus dirancang dan diuji; contoh ringkas ini belum merinci exception tersebut.

4. Contoh estimasi kinerja dan keterbatasan

Ilustrasi: waktu VA tetap 4 menit. Total siklus As-Is 10 menit → PCE 40%. Estimasi total siklus To-Be 6 menit → PCE sekitar 66,7%. Asumsinya beban pelanggan dan lingkup proses sama; hasil To-Be belum menjadi klaim implementasi.

Sisa non-VA dapat meliputi BVA yang penting. Konfirmasi biaya pengadaan, biaya operasi, kesiapan SDM, dan risiko kegagalan layanan sebelum menyatakan proyek layak.

Acuan notasi: OMG BPMN 2.0.2. Diagram ini adalah contoh pembelajaran, bukan model eksekusi mesin atau spesifikasi sistem lengkap.
